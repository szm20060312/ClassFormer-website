# ClassFormer 项目介绍网站

DeepSleep LV.999 三人团队的软件工程课程项目介绍网页。

在线访问：[ClassFormer](https://szm20060312.github.io/ClassFormer-website/)

源码仓库：[ClassFormer-website](https://github.com/szm20060312/ClassFormer-website)

## 项目文件

- `index.html`：页面结构与项目介绍。
- `styles.css`：布局、配色、中英文排版与手机适配。
- `app.js`：语言切换、音频驱动的字幕、课件与疑问回听。
- `assets/classroom-demo.m4a`：英文讲课音频，约 23 秒。
- `assets/classroom-demo-script.txt`：对应的英文讲稿。
- `serve.py`：支持音频时间跳转的本地预览服务。
- `README.md`：使用说明。

打包时将开发目录 `dist/` 的文件放到了压缩包的 `ClassFormer/` 根目录，方便直接使用。网页的相对资源路径保持有效。

## 如何查看

解压后，页面入口为 `ClassFormer/index.html`。可以用浏览器打开。

推荐通过本地 HTTP 服务预览。如果电脑已安装 Python，在解压后的 `ClassFormer` 文件夹打开终端，运行：

```text
python3 serve.py
```

然后访问 `http://localhost:8000/`。网站不需要安装 npm 依赖。此服务仅监听本机，并支持音频回听所需的 HTTP Range 请求。一般的 `python -m http.server` 在部分浏览器中不能准确跳转音频。

部署时，将 `index.html`、`styles.css`、`app.js` 与 `assets/` 一起放到静态网站目录，保持相对路径。

## GitHub Pages 发布

GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 保留静态文件。更新网站后提交并推送到 `main`，GitHub 会自动重新发布。

## 已包含的网页功能

- 默认英文，支持中文 / English 切换并记住语言选择。
- 点击“开始上课”播放老师声音；英文原文和中文字幕按音频进度逐步出现。
- 从空白课堂记录开始，讲到一段新增一段；不会在开课前展示完整讲稿。
- 英文课件根据讲述自动翻页与突出关联要点；手动查看后可恢复跟随。
- 一键“这里没听懂”，保留准确音频秒数与相关讲述，讲课继续播放。
- 课堂结束后自动进入回顾；可以补充疑问说明、移除标记。
- 点击疑问或检索结果，实际回放对应音频，同时定位双语字幕与课件。
- 支持暂停、继续、进度跳转、静音、提前结束与重新开始。
- 对课堂记录或疑问进行关键词检索，并显示无匹配提示。
- 示例双语文字导出。
- 首版与后续范围切换、团队分工和拟议四周计划。
- 桌面、平板与手机布局，键盘焦点和减少动态效果支持。

## 演示与产品阶段

本网站用于介绍项目。使用 [ClassFormer-website 仓库](https://github.com/szm20060312/ClassFormer-website/tree/main/assets)中的讲课音频和讲稿。当前音频实际为全英文授课；课件与原文保持英文，中文翻译辅助理解，界面支持中英文切换。

音频播放器的实际时间驱动字幕与课件。六段起点为 0、3.60、8.21、11.44、14.75、18.91 秒，沿用仓库时序；字幕在每段中渐进呈现。它是预设内容与真实音频同步的产品流程演示，没有调用麦克风、语音识别、实时翻译或自动课件匹配服务。

疑问从零开始，只在当前页面保留；刷新或“重新开始”后清空。本地存储只保存界面语言偏好。音频切到后台会暂停；音频加载失败时显示重试说明，页面不会用空转计时冒充播放。在线字体加载失败时使用系统字体。

## 建议体验方式

1. 点击“开始上课”，观察记录从空白开始，英文声音、原文和中文字幕一起推进。
2. 听到约第 8 秒和第 14 秒时，课件自动切换到第 2、3 页。
3. 听不懂时点击“这里没听懂”。无需先填写说明，声音会继续播放。
4. 音频结束后，在“我的疑问”中补充说明，再点击“回听这一刻”。音频会跳回准确标记时间，字幕与课件一起定位。
5. 在“课堂记录”中搜索 `evidence`，点击结果回听相关讲述。

更换音频时，需要同步调整 `app.js` 中 `segments` 的起点和讲稿；仅替换文件不会自动转录。

演示无需麦克风权限或 API 密钥。它模拟课堂记录与课件的交互关系，不执行真实识别与翻译。
