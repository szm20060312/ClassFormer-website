# ClassFormer 项目介绍网站

DeepSleep LV.999 三人团队的软件工程课程项目介绍网页。

在线访问：[ClassFormer](https://szm20060312.github.io/ClassFormer-website/)

源码仓库：[ClassFormer-website](https://github.com/szm20060312/ClassFormer-website)

## 项目文件

- `index.html`：页面结构与项目介绍。
- `styles.css`：布局、配色、中英文排版与手机适配。
- `app.js`：语言切换与预设课堂交互演示。
- `README.md`：使用说明。
- `serve.py`：支持音频时间跳转的本地预览服务（仅使用 Python 标准库）。
- `assets/classroom-demo-script.txt`：六段全英文授课讲稿。
- `assets/classroom-demo.m4a`：从提供的录屏提取并裁剪的约 23 秒示例讲课音频。

打包时将开发目录 `dist/` 的文件放到了压缩包的 `ClassFormer/` 根目录，方便直接使用。网页的相对资源路径保持有效。

## 如何查看

解压后，页面入口为 `ClassFormer/index.html`。可以用浏览器打开。

推荐通过本地 HTTP 服务预览。如果电脑已安装 Python，在解压后的 `ClassFormer` 文件夹打开终端，运行：

```text
python3 serve.py
```

然后访问 `http://localhost:8000/`。网站不需要安装 npm 依赖。`serve.py` 支持音频所需的 HTTP Range 请求；普通 `python -m http.server` 在部分浏览器中可能无法拖动音频或回听。

部署时，将 `index.html`、`styles.css`、`app.js` 和 `assets/` 文件夹一起放到静态网站目录，保留相对路径。

## GitHub Pages 发布

GitHub Pages 从 `main` 分支的根目录发布网站，`.nojekyll` 保持原始静态文件。修改后提交并推送到 `main`，GitHub 会自动重新发布。网站和源码仓库均公开，访客无需登录。

## 已包含的网页功能

- 默认英文，支持中文 / English 切换并记住语言选择。
- 全英文讲课音频，英文课件与英文原文配合中文字幕；支持播放、暂停、拖动进度与重播。
- 课件页示意、手动选择与恢复示例自动关联。
- 疑问标记、文字说明、片段回听及移除；检索和疑问回跳会定位并播放对应音频。
- 示例记录的关键词检索及无匹配提示。
- 示例双语文字导出。
- 首版与后续范围切换、团队分工和拟议四周计划。
- 桌面、平板与手机布局，键盘焦点和减少动态效果支持。

## 演示与产品阶段

本网站用于介绍项目。当前演示为全英文授课场景：课件和授课原文始终使用英文，中文译文辅助理解，界面说明可中英切换。课堂内容、时间点及页码关联均为预设示例；演示未连接麦克风、语音识别、实时翻译或课件匹配服务。网页中已经注明当前为提案与需求准备阶段，未来功能不作为首版已实现能力。

示例音频从用户提供的录屏中提取，保留六段英文讲述，并裁掉开头 4.8 秒和结尾约 1.2 秒的静音。音频长约 23.35 秒；字幕时间点依据录音中的各段起点校准，课件随音频切换。中文译文不作为音频朗读内容。

原生音频控件与“播放演示”控制同一个播放器；标记疑问或切换到后台会暂停播放。检索结果和疑问标记会跳到对应讲述并播放。手动选择课件页后保持手动模式，点击“恢复自动”重新跟随音频。界面说明可中英切换，授课内容始终保留英文。

## 更换音频

替换 `assets/classroom-demo.m4a` 后，根据新的讲述校准 `app.js` 中每段的 `start`（秒）和 `time`（显示时间）。`assets/classroom-demo-script.txt` 保存当前的英文讲稿。若改用其他音频格式，需要同步调整 `index.html` 中 `#demo-audio` 的 `<source>` 路径和 MIME 类型。

疑问标记只在当前页面保留，刷新后清空；本地存储只保存界面语言偏好。在线字体加载失败时使用系统字体。
